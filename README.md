# LEADBREAK

2D/2.5D anime/manga-styled platform fighter with irreverent character identity, dynamic stages and creator-friendly arena construction.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3 for shell/meta where useful; **FightingGameTemplate** primary accelerator; Boss Fight Arena/PVP Arena for arena reference; Game Animation Sample; Couch Coop Local Multiplayer Template; movement/combat modules only when they fit platform-fighter requirements rather than action-RPG assumptions.

## Gates
V1: 4 fighters, core platform-fighter rules, local play, 3 stages, manga visual treatment. V2: roster/content, online rollback-oriented architecture, ranked, stage editor. V3: tournaments/social/creator ecosystem + AXIOM/PYRAMID edition.

See `MASTER_BLUEPRINT.md`.
